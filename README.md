# سَلّة — أداة تحليل سلة المشتريات

> **منصّة تحليل سلة المشتريات** — اكتشف المنتجات التي تُشترى معًا داخل متجرك باستخدام
> خوارزمية Apriori، وحوّل سجلّ المعاملات إلى قرارات عرض وتسويق فورية.

تطبيق سطح مكتب (Python + PyQt6) بواجهة عربية كاملة من اليمين إلى اليسار، مبني على هوية
بصرية خاصة: أزرق كحلي للبيانات، أزرق سماوي للوضوح، وشعار «سلة» تحمل أعمدة صاعدة ترمز للنمو.

---

## المزايا

| | |
|---|---|
| **إدخال CSV** | كشف تلقائي لثلاثة تنسيقات: سلة في صف واحد، سجل طويل (Transaction-Item)، وجدول عريض بأعمدة 0/1 |
| **ضبط المعاملات** | الحد الأدنى للدعم، الحد الأدنى للثقة، الحد الأدنى للرفع، أقصى طول للمجموعة |
| **تنفيذ Apriori** | تنفيذ كامل من الصفر: توليد المرشحين، القصّ بخاصية Apriori، حساب الدعم عبر تقاطع قوائم الظهور |
| **المتجهات المتكررة** | جدول قابل للترتيب مع الدعم وعدد المعاملات |
| **قواعد الارتباط** | الدعم، Confidence، Lift، Leverage، Conviction |
| **الرسوم البيانية** | أعمدة المتجهات المتكررة، مخطط ثقة/رفع، خريطة حرارية، شبكة ثنائية للقواعد، توزيع حجم السلة |
| **توصيات جاهزة** | صياغة عملية لكل قاعدة: أي منتجين يُعرضان معًا، وبأي ثقة |
| **التصدير** | CSV بترميز UTF-8 BOM يعمل مباشرة في Excel |

## التشغيل

```bash
# 1) تثبيت المتطلبات
pip install -r requirements.txt

# 2) تشغيل التطبيق
python3 main.py

# 3) تشغيل سطر الأوامر (للاستخدام في السكربتات)
python3 cli.py data/sample_transactions.csv --min-support 0.10 --min-confidence 0.6
```

أو عبر مشغّل جاهز:

```bash
./run.sh
```

## الخوارزمية

```
L₁    حساب دعم كل منتج منفرد، واستبعاد ما دون الحد الأدنى
Cₖ    دمج المجموعات المتكررة السابقة (Self-Join) لتوليد المرشحين
Prune قصّ أي مرشح لا تتكرّر كل مجموعاته الجزئية  ← خاصية Apriori
Rules اشتقاق القواعد بحساب الثقة والرفع لكل تقسيم للمجموعة
```

**المؤشرات**

- `support` — نسبة المعاملات التي تحتوي المجموعة كاملة
- `confidence` — احتمال شراء المنتج المتْبع عند شراء المُقدِّم
- `lift` — كم مرة يكون الشراء أكثر احتمالًا مقارنة بالصدفة (‎> 1‎ يعني ارتباطًا حقيقيًا)
- `leverage` — نسبة التحسّن الحقيقي عن الصدفة
- `conviction` — قوة الدليل ضد احتمالات الشراء العشوائي
